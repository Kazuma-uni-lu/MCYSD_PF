# MCYSD_PF
Cyber Escape Room Project Group 5
Description of the project can be found in Cyber Escape-Room Shared-Task Description.ipynb

Start the escape room with:
```
python escape.py --start intro --transcript run.txt
```
The commands supported are:
```
look
move <room>
inspect <item>
use gate (in final gate)
iventory
save <savefilename>
load <savefilename>
quit
```
